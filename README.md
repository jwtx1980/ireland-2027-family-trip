# Ireland 2027 family trip

A static, account-free family review site for the proposed Ireland trip.

## Privacy model

- The published site is public.
- It contains first names, candidate lodging links and trip-planning estimates.
- Choices and calculator values stay in the visitor's browser using `localStorage`.
- Nothing is submitted to a database. Family members coordinate by copying or texting their summary.

## Updating the site

Edit the HTML, CSS, JavaScript or lodging data and push to `main`. The GitHub Pages workflow publishes the new version automatically.

Listing photos remain hosted by the source listing provider and may change or stop loading. The linked listing is always the source of truth.
